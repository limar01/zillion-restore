🔐 Security Model

  • All exec channels = HMAC-SHA256 signed envelope {"d","h"}
  • Only non-HMAC op = bootstrap (pre-key): sha256(passphrase) check + rate limit 5 fails / 900s
  • Passphrase goes ONLY to the trusted url.txt origin — never beacon-derived URLs
  • Public repo = clone surface by design (no secrets) · private vault = tunnel-adb + phone _pack + SD
  • 3-copy redundancy: GitHub · phone ~/zillion_pw/_pack · SanDisk mirror
